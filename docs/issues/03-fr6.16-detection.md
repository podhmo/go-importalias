# 03: FR-6.16（単一ファイル内の重複 import）検出

## 目的

1 つのファイル内で同一 import path が複数回、異なる alias で import されているケース（FR-6.16、1 ファイルで完結する重複 import）を検出する。ファイル跨ぎの FR-6.10 とは別軸として明示的に検出範囲に含める。

## 対象 DEC・FR

- FR-6.16（単一ファイル内で同一 path が複数回・異なる alias で import → 検出。staticcheck ST1019 相当だが本ツールの範囲にも明示的に含める）
- DEC-11.4（検出ロジックは純粋関数）

## 変更ファイル

- `internal/scan/scan.go` または `internal/decide/decide.go`（同一 file 内で同一 path が複数回現れることを検出する。実装場所は walking skeleton で確定＝DEC-7.5 に従い実装しながら `docs/02notice.md` に知見を残す）
- `analyzer.go`（報告）
- 必要なら `internal/shape/model.go`（重複 import を表す検出結果の保持方法。既存 `Occurrence` に file 単位の情報を足すか、専用の軽い型を足すか。過剰にならない範囲で）

## 実装メモ

- `Occurrence` は既に `Pos`（import 宣言位置）を持つ。同一 file・同一 path・複数 alias の判定は、file 単位で import をグルーピングすれば可能。
- FR-6.10（パッケージ内・ファイル跨ぎ）の多数決とは概念が異なるので、**別軸の検出**として扱い、同じ集計に混ぜない。
- 実装場所を scan/decide のどちらにするかは、「file 単位の情報が scan にしかない」点を踏まえて判断する。決めた根拠を `docs/02notice.md` に追記する。
- **auto-fix（重複統合）はスコープ外**。fix は 10 で扱う。
